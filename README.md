# stozapad — редизайн главной stozapad.by

Статичная страница для GitHub Pages: `index.html` + `assets/`.

- `assets/css/style.css` — стили, анимации, адаптив
- `assets/js/main.js` — схема «Где беспокоит?» (точки на авто → симптомы → работы в расчёт), выбор дня и времени визита, параллакс и «фары» в hero, наклон карточек, прогресс прокрутки, меню, появление блоков, счётчики, калькулятор (добавление/удаление услуг, количество, «Вернуть», сохранение в браузере)
- `assets/img/*.webp` — фото, сжатые и обрезанные под блоки. `loc-*`, `workshop`, `svc-wheel` — с сайта компании rs-auto.by; остальные — Unsplash (лицензия Unsplash: бесплатно, в т. ч. для коммерции).

Цены в калькуляторе — «от»: со страниц услуг stozapad.by, где цены нет — из общего прайса stozapad.by/ceny. Скидка −20% на каждый второй элемент кузова считается автоматически. Кнопка «Записаться с этим расчётом» пока открывает письмо на mavra41@bk.ru — заменить на отправку в CRM / Telegram-бота.
