# stozapad — редизайн главной stozapad.by

Статичная страница для GitHub Pages: `index.html` + `assets/`.

- `assets/css/style.css` — стили, анимации, адаптив
- `assets/js/main.js` — схема «Где беспокоит?» (точки на авто → симптомы → работы в расчёт), выбор дня и времени визита, параллакс и «фары» в hero, наклон карточек, прогресс прокрутки, меню, появление блоков, счётчики, калькулятор (добавление/удаление услуг, количество, «Вернуть», сохранение в браузере)
- `assets/img/*.webp` — фото, сжатые и обрезанные под блоки. Источник — Unsplash (лицензия Unsplash: бесплатно, в т. ч. для коммерции, без обязательной атрибуции). Перед запуском лучше заменить на собственные фото цеха и работ.

Цены в калькуляторе — «от», из прайса stozapad.by/ceny. Кнопка «Записаться с этим расчётом» пока открывает письмо на mavra41@bk.ru — заменить на отправку в CRM / Telegram-бота.
